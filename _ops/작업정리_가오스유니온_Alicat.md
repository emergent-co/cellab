## 1. 가오스유니온 (Gaoss Union) — 전기화학 838 SKU

### 데이터 파이프라인 (가격의 신뢰성)
- 원천 = 제조사 **2026 카탈로그 PDF 3권**(배터리 테스트 셀 / 전해셀 / Flow·In-situ·MEA). 원본 8~35MB는 Cloudflare 25MiB 제한에 걸리므로 **압축본만 리포에 보관**(`_ops/gaossunion_pricelist_2026_*.pdf`).
- 가격 산출 규칙을 고정: **정가 = 카탈로그 EUR × 환율, 1,000원 단위 반올림, 마진 0(카탈로그가=소비자가)**. 환율 1,620원으로 시작해 **1,750원으로 일괄 개정** 경험 후, 재산출 절차를 `_ops/gaossunion_price_recalc.md`로 문서화(바꿀 지점 3곳만: SQL 주석 기준환율 · GU- SKU retail_price · 상세페이지 pkg-note).
- 정책 원칙: **3% 상시 할인 대상 아님**(홈 가격 키에 넣지 않는 방식으로 자동 배제), **국제 운송비 별도** 문구 유지, 카탈로그 오류 의심 가격 3건은 채우지 않고 "문의" 처리(임의 추정 금지).
- 최종 SQL(SSOT) `rndsetup_products.sql`에 **GU- SKU 838행** 병합. 병합 완료 조각(`_ops/gaossunion_products.sql`)은 재병합 금지 주석으로 봉인.

### 상세페이지 (계열 단위 21장)
- 전극 5(기준·RHE·상대·작업·RDE/RRDE), 소모품·재료 3(클램프홀더·연마용품·전기화학재료), CO₂RR 촉매, 셀 10(단실유리·격막교환·부식/석영·광전기화학·in-situ분광·가스확산GDE·MEA·고압·리튬 in-situ 특수·배터리 테스트 셀) + glass-cell 하위 모델 페이지(c001·c002·c004).
- 페이지 구성에서 신경 쓴 것: **모델별 정가표**(EUR 근거), 카탈로그 **원문 설명 복원**(glass-cell 34항목), **사진 부위별 넘버링**, 국·영문 병기, pkg-note에 환율 기준 명시.

### 이미지 (115장, `img/gaossunion/<slug>-<n>.jpg`)
- 제조사 카탈로그 PDF에서 추출(사용 허가 확보). 투명 이미지가 깨진 경우 **SMask 재추출**로 복원.
- 배경 정리 2단계: 순흑 배경 전체를 플러드필로 1차 백색화 → 홈·카드 노출 대표컷 12장은 **나노바나나(Gemini API)로 스튜디오 흰 배경 재생성**(제품 형상 유지 프롬프트, 모서리 254~255 검수).

### 카드·검색·홈 연동 (자동화)
- 허브 `brands/gaossunion/index.html`의 dscard → 빌드가 **통합 카탈로그 표준 카드**(스펙 3행·#키워드 7·최저가)로 자동 수집. 계열 슬러그→SQL sobun 매핑으로 **최저가 자동 표기**, 할인 배지 없이 "최소 N원부터"만.
- 검색: 기준전극/reference electrode 등 **계열별 동의어**, 자동완성 대표 키워드(기준·상대·작업전극, RDE, 전해셀, CO₂RR 촉매 등) 등록.
- 홈 **전기화학·수전해 코너**를 실제 라인업 기준 12칸(계열별 종수·최저가·실사진·상세 직링크)으로 재구성, 전극 4칸도 가오스 실사진으로 교체(타사 이미지 제거).

## 2. Alicat — 질량유량계·압력 컨트롤러 46 SKU

### 상세페이지 (시리즈 12장 + 가이드/메뉴얼)
- MC(표준)·MCS(내부식)·MCQ(고압)·MCD(양방향)·MCT(2가스)·BIOC(바이오)·MCV/SFF(진공)·PC·PCD(압력)·BPR(배압)·BASIS(소형)·통합 컨트롤러 + `mfc-guide`(선택 가이드) + `manual`.
- 정품 이미지 사용, 시리즈 상세 12p 체계로 신설(커밋 219dec2).

### 인터랙티브 자료 (차별화 포인트)
- **LCD 시뮬레이터**: 실제 기기 화면을 재현 — 도트매트릭스 폰트, 실제 메뉴맵(Main Menu·Basic Config), 유량 설정 digit 커서 편집, 버튼·비율·여백까지 실물 매칭으로 수 차례 다듬음.
- **사용 메뉴얼 페이지**: SCCM 유량 설정·Gas Select 가스 변경 절차를 HowTo·FAQ 스키마로 정적 렌더.

### 카드·콘텐츠 연동
- 통합 카탈로그 gas 카테고리 서브필터(시리즈/공정 3축), NAV 하위메뉴로 메뉴얼 연결.
- 도입 사례 콘텐츠와 교차 연결: "1500℃ 튜브퍼니스 가스 분위기 제어 — Alicat MFC 도입 사례", 블로그·셋업 글 대표사진(og) 정리.
- 가격: SQL 46행 등록, MC·MCS·BPR·BASIS 등은 최저가 노출, 정가 미확보 시리즈는 견적 유지(근사 매칭으로 잘못된 가격을 붙이지 않음).

## 3. 공통으로 지킨 원칙

1. **SSOT·갱신 1곳**: 가격은 SQL, 카드는 브랜드 허브 dscard, 나머지(카탈로그·sitemap·검색인덱스·자동완성 수치)는 전부 빌드 자동 파생.
2. **GEO 우선**: 카드·크럼·FAQ/HowTo/Product JSON-LD 정적 렌더, 크럼은 `홈 › 제품 › 계열`로 통일.
3. **저작권**: 제조사 허가 이미지만 사용(가오스 카탈로그 추출·Alicat 정품컷), 출처 불명 타사 이미지는 발견 즉시 교체.
4. **가격 보수 원칙**: 근거 없는 가격은 표시하지 않음 — 카탈로그 오류 의심분·미확보 시리즈는 "문의" 유지.
5. **사고 대응 기록**: 25MiB 배포 차단(PDF 압축), 병렬 세션 덮어쓰기(go.ps1 단일 세션 원칙), 환율 개정 절차서 등 재발 방지 문서화.
