## 원본을 저장소 루트에 두지 말 것

원본은 8~35 MB로, 루트에 커밋하면 **Cloudflare Pages 배포가 통째로 막힌다.**
`.gitignore`에 원본 파일명이 등재돼 있으니 다시 떨어뜨려도 커밋되지 않는다.
치워둔 원본은 `_to_delete/root-pdf/` 에 있다(삭제 권한이 없어 이동만 함).

## 압축 방법 (새 카탈로그가 올 때)

```bash
gs -sDEVICE=pdfwrite -dCompatibilityLevel=1.5 -dPDFSETTINGS=/ebook \
   -dNOPAUSE -dQUIET -dBATCH \
   -sOutputFile=_ops/gaossunion_pricelist_2026_<이름>.pdf "<원본.pdf>"
```

`/ebook` 프리셋은 **텍스트 레이어와 표 숫자를 그대로 보존**한다. 압축 후 반드시 확인할 것:

```bash
python3 -c "import pymupdf; d=pymupdf.open('_ops/<파일>.pdf'); print(len(d), len(d[3].get_text()))"
```

페이지 수가 원본과 같고 표본 페이지 텍스트가 살아 있으면 정상이다.

## 가격 판독 주의

`pdftotext -layout` 추출값이 **한 자리씩 깨지는 페이지가 있다**(예: 1,100 → 110).
가격을 SQL·페이지에 넣기 전 **해당 PDF 페이지를 이미지로 열어 눈으로 대조**할 것.
전해셀 p15·p28에서 실제로 발생했다.
