# 가오스유니온 가격 재산출 절차 (환율 변경 시)

정가 = 카탈로그 EUR × 환율, **1,000원 단위 반올림**. 마진 0 (카탈로그가 = 소비자가).
현재 기준: **EUR 1 = 1,620원** (2026-08-22).

## 바꿀 지점 — 3곳뿐

1. `rndsetup_products.sql` 상단 가오스 블록 주석의 기준 환율
2. 같은 파일에서 `GU-` 로 시작하는 SKU 322행의 `retail_price`
3. 상세페이지 10장의 `pkg-note` 문구 `EUR 1 = 1,620원` 과 정가 표(`brands/gaossunion/**/index.html`)

## 주의

- **3% 상시 할인 대상이 아니다.** `build_prices()`의 가격 키(`muffle1050`·`pumplab` 등)에 가오스 품목을 넣지 말 것.
  키에 걸리는 순간 홈 시작가가 자동으로 3% 깎인다.
- 국제 운송비 별도 문구를 지우지 말 것.
- 가격 미정 3건(금선전극 주문제작, `Pt2020-5`, `Cu-CTUH`)은 카탈로그 오류 의심분이라 "문의"로 둔 것.
  제조사 확인 후 값이 오면 그때 채운다.
- `_ops/gaossunion_products.sql` 은 이미 병합된 조각이다. **다시 붙여넣지 말 것.**
