# 2~5단계 작업지시서 — 제품 라인업 → 유입 엔진 → 진짜다움 → 백과사전

> 1단계(할인가·FAQ 통합·메뉴 축소·제품 등록 스킬)를 끝낸 세션에서 이어서 진행한다.
> 시작 전 `CLAUDE.md` → `CRITICAL_RULES.md` → `OPERATIONS.md` 재확인. 시작 시 `.\go.ps1` 동기화.
> 대원칙: GEO 0순위 · 갱신 1곳 원칙 · 파일 하나씩 편집 · 삭제 = 파일 삭제 + 1홉 301 세트.
> **각 단계는 시작 전에 사용자에게 착수 확인을 받고, 끝나면 배포 명령을 안내한 뒤 다음 단계로.**

## ⚠️ 병렬 세션 경계 (중요)

다른 Cowork 세션이 아래 작업을 진행 중이다. **이 파일들은 절대 수정하지 말 것** (수정하면 서로 덮어씀):
- `magazine/*/index.html` 전체, `setups/*.html` 3편 (AI 문체 다듬기 + 셋업 다이어그램 삽입 중)
- `img/magazine/` (셋업 다이어그램 저장소)
- `_build/posts.json` (썸네일 교체 중 — 새 글 발행으로 항목 "추가"만 허용, 기존 항목 수정 금지)
- 로드맵 4단계 중 "AI 티 제거"는 저쪽 담당이므로 이 세션에서는 하지 않는다.

새 글 발행(3단계)은 신규 디렉토리 생성이라 충돌 없음.

## 2단계 — 제품 라인업 (원스톱의 뼈대)

목표: "에너지·배터리·수전해 실험의 자료·장비·소모품·시약 **원스톱**"이 실제 상품으로 성립하게 만든다.
도구: 1단계에서 만든 `rndsetup-product-page` 스킬. 가격은 `rndsetup_products.sql`(SSOT)에만 넣으면 할인가 자동 반영.

### 2-1. 전기화학 코너 제품 등록 (최우선)
- 홈 전기화학 코너의 10개 품목(전극 4종: 작업·상대·기준·전극 / 셀 6종: 전기화학·광전기화학·분광전기화학·GDE 플로우·MEA 수전해·PSE 리액터)을 실제 상세페이지로.
- 브랜드 슬러그 `electrochem` (`brands/electrochem/<product-slug>/`). 브랜드 허브도 생성.
- **사용자에게 먼저 물을 것**: 품목별 공급가·정가, 사양(치수·재질), 소싱처. 없으면 "견적 문의형"(가격 미표기, 문의 버튼)으로 등록.
- 이미지: `img/electrochem/*.jpg` (AI 생성분, 파일명 고정) 재사용. 소싱 확정 시 같은 파일명으로 덮어쓰기만.
- 홈 oc-grid 카드의 견적 팝업 → 상세페이지 링크로 전환.

### 2-2. 가오스유니온(재료·시약) 등록
- 슬러그 `gaossunion`. 사용자에게 취급 품목 리스트·가격표 요청 후 카테고리 단위 등록.
- 홈 재료·시약(mat-band) 밴드 → 허브 연결. "머크 에너지 시약" 컨셉 문구는 확정 전까지 넣지 않는다(신규 약속 동결).

### 2-3. 뉴웨어(충방전기) 등록
- 슬러그 `neware`. 대표 모델(코인셀용 사이클러 등)부터. 배터리 커리큘럼 ⑧화성·사이클 단계와 상호 링크.

### 2-4. 원스톱 컨셉 문구 일관화
- 홈 소개 2줄·`about/`·Organization JSON-LD(description·knowsAbout)에 "자료·장비·소모품·시약 원스톱" 서술을 1회씩, 같은 문장으로. (Org 스키마는 build.py HEADLD가 전 페이지 주입 — **build.py의 원본 1곳만 수정**.)

완료 기준: 신규 상세페이지 전부 스킬 산출 규격(정답블록·사양표·JSON-LD 3종·견적 버튼) 통과, 가격은 SQL 경유, 빌드 후 사이트맵·검색 인덱스 자동 포함, 죽은 링크 0.

## 3단계 — 유입 엔진 (콘텐츠 = 랜딩)

### 3-1. 배터리 커리큘럼 잔여 단계 글 작성
- 허브: `magazine/battery/` (①공침 ②소성 ③탄소코팅 은 live, 나머지 todo).
- **④ 슬러리 믹싱·전극 코팅은 논문 리서치가 끝나 있다** — 아래 팩트로 `paper-setup-magazine` 스킬을 써서 작성:
  - 논문: Hoffmann et al., *Energy Technology* 2023, DOI `10.1002/ente.202200484` (오픈액세스 CC BY, ZSW). 전문: https://d-nb.info/1269061526/34
  - 핵심: NCM622:CB:흑연:PVdF=93:2:1:4 동일 배합에서 믹싱 전략 3종(HS1 고전단·고형분 73.5% / HS2 고전단·73.1% / LS 저전단·65.0%, 10 L 플래니터리 믹서 Netzsch) 비교. LS(바인더액에 CB 55분→흑연 65분→활물질 3분할 투입, 50/500 rpm)가 tortuosity 12.5→5.5, 8 mA/cm² 면적용량 +67%, 에너지밀도 최대 +81%, φ80 권취 균열 0. 건조 4구역 50/70/90/110℃, 캘린더 100℃·~3.0 g/cm³, 2032 코인셀·C/10 화성·1~12 mA/cm² 율속.
  - 메커니즘: 고전단은 CB가 잘게 부서져 활물질 표면을 막처럼 덮어 기공 차단, 저전단은 스펀지형 다공 CBD 네트워크.
  - 제목 예: "같은 레시피, 성능은 81% 차이 — NCM622 초후막 전극의 슬러리 믹싱 순서"
  - 발행 절차: 글 디렉토리 + posts.json 1건 **추가** + 배터리 허브 4단계 todo→live 전환.
- 이후 ⑤건조·수분 ⑥코인셀 조립 ⑦전해액 ⑧화성·사이클 순으로 한 편씩(각 편마다 오픈액세스 논문 1편 리서치 → 스킬 작성). 한 번에 몰아 쓰지 말고 편당 사용자 확인.

### 3-2. Search Console 루프
- 사용자에게 Search Console 접근을 요청해 상위 유입 쿼리·노출 페이지 확인 → 정답블록·제목을 실제 쿼리 어휘로 보정. 월 1회 루틴으로 문서화(`OPERATIONS.md`에 추가).

완료 기준: 커리큘럼 8단계 전부 live, 각 글이 정답블록·조건표·장비레일·문의 팝업 규격 통과.

## 4단계 — 진짜다움 + Q&A 자산화

(※ "AI 문체 제거"는 다른 세션 담당 — 여기서는 하지 않는다.)

- **Q&A 자산화**: 실제 들어온 문의·견적 문답에서 반복 질문을 골라(개인정보·회사명 제거) `/contact/` FAQ에 축적. 분기마다 FAQPage 스키마에 반영. "실제 문의에서 발췌" 표기로 진짜다움 확보.
- **실물 사진 배치**: 사용자가 제공하는 납품·설치·수리 현장 사진을 도입 사례·상세페이지에 배치(`img/cases/`). 파일명 규칙: `<brand-or-case>-<n>.jpg`.
- **도입 사례 확충**: 실제 납품 건을 "증상→구성→결과" 3단 구조 사례 글로. 셋업 사례 허브에 추가.

완료 기준: FAQ에 실문의 기반 문항 5+ 추가, 사례 글 2+ 발행, 사진 없는 사례 0.

## 5단계 — 에너지 랩 A to Z 백과사전화

- `magazine/battery/`(커리큘럼)를 축으로, 용어사전 2편·가이드·트러블슈팅을 **표제어 단위 그물**로 연결: 각 글에서 처음 나오는 핵심 용어에 용어사전 앵커 링크, 용어사전 항목에서 관련 커리큘럼 단계 역링크.
- 공정 허브(deposition·heat-treatment·oxidation)도 커리큘럼과 동일한 단계형 구조로 정돈.
- DefinedTermSet 스키마를 용어사전에 유지·확장. `llms.txt`에 백과 구조 서술 갱신.
- 신규 표제어 페이지는 "이게 바뀔 때 수정 지점 1곳인가"를 통과할 때만 생성 — 안 되면 기존 용어사전 내 앵커로.

완료 기준: 커리큘럼↔용어사전↔가이드 상호링크 그물 완성, 고아 페이지 0, llms.txt 일치.
