SH SCIENTIFIC · 칸탈 머플전기로 MG·MGE

칸탈 머플전기로 · 온도컨트롤러 메뉴얼

1050℃(MGE)·1200℃(MG) 칸탈 머플전기로의 기본 탑재 디지털 컨트롤러(TEMP & TIME CONTROL SYSTEM) 조작법입니다. 이 컨트롤러에는 다단 승온 스케줄(프로그램) 기능이 없습니다 — 스케줄 운전이 필요하면 SP570/SP590 옵션 모델을 확인하세요(SP590 가이드 →). 안전: 고온 표면 주의 · 가연물 이격 · 인화성 시료 투입 금지.

SH Scientific 칸탈 머플전기로(MG·MGE)는 TEMP(목표온도) · TIME(운전시간) · BEEP(종료부저) 3가지만 설정합니다. 전원 버튼 3초 = 운전 시작/정지, AT 5초 = 오토튜닝. 다단 스케줄은 SP570/SP590 옵션에서 지원합니다.

전원 대기 — MODE 버튼을 꾹(3초) 누르면 TEMP 설정으로 들어갑니다.

※ 연습용 시뮬레이터라 시간을 압축했습니다 — "3초 꾹"은 여기서 약 1.2초, "5초 꾹"은 약 2초 길게 누르면 되고, 승온·타이머도 가속되어 표시됩니다. 실제 기기는 표기된 시간(3초/5초) 기준입니다.

연습 체크리스트

시뮬레이터에서 직접 해보면 자동으로 체크됩니다.

  1. TEMP — 목표온도 설정·저장
  2. TIME — 운전시간 설정 (hr.min)
  3. BEEP — 종료 부저 설정
  4. 전원 3초 — 운전 시작
  5. AT 5초 — 오토튜닝 실행
  6. 운전 중 출력·남은시간 확인
  7. 운전 정지 / 자동 종료(End)

MG 시리즈 사용법 — SH-FU-3MG·5MG·7MG·14MG·27MG·64MG·100MG

1200℃ 칸탈 머플전기로 기본 컨트롤러. 표시창 2단 — 위 = 현재온도(PV), 아래 = 설정값(SV). 램프: ON(운전 중) · OUT(히터 동작 시 점등/점멸) · A·P(DOOR) 램프는 본 제품과 무관. 버튼: 전원 · MODE · ◀ ▶(자리 이동) · ▲(값 변경) · AT.

(1) TEMP 모드 — 목표온도 설정

  1. MODE 버튼을 3초간 누르면 표시창에 tEMP가 표시됩니다.
  2. 이동(◀▶)·변경(▲) 버튼으로 목표온도를 입력합니다. (예: 800)
  3. MODE 1초 = 설정값 저장 / MODE 3초 = 저장 후 초기화면 복귀.

(2) TIME 모드 — 운전시간 설정

  1. TEMP 설정 후 MODE를 눌러 tiME로 진입합니다.
  2. 이동/변경 버튼으로 시간을 입력합니다 — 표기는 hr.min(시.분), 최대 99시간 59분. (예: 01.30 = 1시간 30분)
  3. 00.00 설정 시 = 사용자가 운전을 종료할 때까지 연속 운전합니다.
  4. MODE 1초 저장 / 3초 저장 후 초기화면.

hr.min을 min.sec 또는 day.hr 단위로 변경해 사용하려면 제조사 C/S팀(cs@samheung21.com)에 문의하세요.

(3) BEEP 모드 — 종료 부저 설정

  1. TIME 설정 후 MODE를 눌러 bEEP로 진입합니다.
  2. 부저가 울릴 시간을 입력합니다. (예: 0030 = 운전시간 종료 후 부저 30초)
  3. MODE 1초 저장 / 3초 저장 후 초기화면.

BEEP은 TIME이 설정된 경우에만 동작합니다. TIME이 00.00이면 BEEP 값을 설정해도 부저가 울리지 않습니다.

(4) 운전 시작

전원 버튼을 3초간 누르면 ON 램프가 점등되며 운전을 시작합니다. OUT 램프는 히터가 동작할 때 점등/점멸합니다. Lamp A·Lamp P(DOOR)의 동작은 본 제품과 관련이 없습니다.

(5) 운전 정지

TIME이 00.00인 경우TIME에 시간이 설정된 경우
전원 3초 → ON 램프가 꺼지면서 정지합니다.설정 시간 종료 후 자동 정지되고 표시창에 End가 표시됩니다. 전원을 누르면 초기화면으로 전환됩니다.

운전 직후 노 내부·도어는 매우 뜨겁습니다. 충분히 냉각된 후 도어를 여세요.

(6) 오토튜닝 (AT)

다음 2가지 경우에 사용합니다: ① 온도조절기 표시부의 온도 변화가 ±0.1℃ 이상 흔들릴 때 ② 설정온도에 도달하지 못할 때.

  • 제품 운전 중 AT를 5초간 누르면 AT가 작동합니다(표시 At).
  • AT 작동 중 AT를 5초간 누르면 중지됩니다.
  • AT는 장비 운전 중에만 작동시킬 수 있으며, 자동으로 완료됩니다.

(7) 히터 출력·남은 운전시간 확인

  1. 운전 중 AT를 1초 누르면 히터 출력%가 표시됩니다. (0.100=100% · 0.60=60% · 0.30=30%)
  2. 한 번 더 누르면 남은 운전시간(hr.min)이 표시됩니다.
  3. 한 번 더 누르면 처음 화면으로 되돌아갑니다.

MGE 시리즈 사용법 — SH-FU-3MGE·5MGE·7MGE·11MGE

1050℃ 칸탈 머플전기로 기본 컨트롤러. 표시창 1단. 램프: RUN(운전 중) · OUT1(히터 동작 시 점등/점멸) · TIMER(설정온도 도달 전 점멸, 도달 시 점등) · OUT2는 본 제품과 무관. 버튼: 전원 · MODE · ◀(자리 이동) · ▼ ▲(값 변경).

(1) Temp 모드 — 목표온도 설정

  1. MODE 버튼을 누르면 tEMP가 표시됩니다.
  2. MODE를 한 번 더 누른 후 이동(◀)·변경(▼▲) 버튼으로 목표온도를 입력합니다.
  3. MODE를 눌러 설정값을 저장합니다.

(2) Time 모드 — 운전시간 설정

  1. TEMP 설정 후 MODE를 눌러 tiME로 진입합니다.
  2. 값을 입력합니다 — 표기 hr.min, 최대 99시간 59분, 00.00 = 사용자가 종료할 때까지 연속 운전.
  3. MODE를 눌러 저장하고, MODE를 한 번 더 눌러 초기화면으로 나옵니다.

(3) Beep 모드 — 종료 부저 설정

  1. MODE 버튼을 3초간 눌러 BEEP 모드로 진입합니다(bEEP 표시).
  2. MODE를 한 번 더 눌러 BEEP 설정으로 들어갑니다.
  3. 이동/변경 버튼으로 부저 시간을 설정한 후 MODE를 3초간 눌러 운전화면으로 나옵니다.

BEEP 값 = 부저 동작시간. 예: 0030 = 운전시간 종료 후 부저 30초. TIME이 00.00이면 BEEP을 설정해도 울리지 않습니다.

(4) 운전 시작 / 정지

  • 전원 3초 → RUN 램프 점등, 운전 시작. / 다시 3초 → RUN 램프 소등, 정지.
  • OUT1 램프 = 히터 동작 시 점등/점멸. TIMER 램프 = 설정온도 도달 전 점멸, 도달 시 점등. OUT2 램프의 동작은 본 제품과 관계가 없습니다.

(5) 오토튜닝 (AT)

사용 조건은 MG와 동일합니다(표시온도 ±0.1℃ 이상 흔들림 · 설정온도 미도달). 제품 운전 중 ▲를 5초간 누르면 AT가 작동하고(표시 At), AT 작동 중 5초간 누르면 중지됩니다. 운전 중에만 작동하며 자동으로 완료됩니다.

(6) 히터 출력·남은 운전시간 확인

  1. 운전 중 ▲를 1초 누르면 히터 출력%가 표시됩니다. (0.100=100% · 0.60=60% · 0.30=30%)
  2. 한 번 더 누르면 남은 운전시간(hr.min), 한 번 더 누르면 처음 화면으로 돌아갑니다.

자주 묻는 질문 (FAQ)

운전이 끝났는데 부저가 안 울려요

BEEP은 TIME(운전시간)이 설정된 경우에만 동작합니다. TIME이 00.00(연속 운전)이면 BEEP 값을 설정해도 울리지 않습니다.

온도가 흔들리거나 설정온도에 도달하지 못해요

운전 중 오토튜닝(AT)을 실행하세요 — MG는 AT 버튼, MGE는 ▲ 버튼 5초. 기기 상태에 따라 30~40분 이상 걸릴 수 있으며 자동 완료됩니다.

시간 단위를 분.초(min.sec)로 바꾸고 싶어요

기본은 hr.min입니다. min.sec·day.hr 변경은 제조사 C/S팀(cs@samheung21.com) 문의.

A·P(DOOR)/OUT2 램프가 동작하지 않아요

해당 램프들은 본 제품과 관련이 없습니다. 동작하지 않는 것이 정상입니다.

다단 승온 스케줄(프로그램 운전)을 하고 싶어요

MG·MGE 기본 컨트롤러는 미지원입니다. 프로그램 컨트롤러(SP570/SP590) 옵션 모델을 선택하세요 — SP590 사용법·시뮬레이터 →
