퍼퍼니스SH SCIENTIFIC · 전기로·튜브퍼니스+
삼흥에너지 관상형(튜브)·박스형(머플로) 전기로. 대부분 SP590 온도컨트롤러가 탑재됩니다(설정·문제해결은 아래 온도컨트롤러 카드 참고).

⚠ 안전 주의

  • 과열 방지 — 과온 알람·차단 확인, 이상 승온 시 즉시 정지.
  • 가연성·환원 가스(H₂) — 누설·환기·점화원 관리, 배기·인터록 필수.
  • 고온 표면 — 충분히 냉각 후 취급.
  • 소모품 — 발열체·열전대·실링 수명 저하 시 온도 편차·고장의 원인.

상시 사용 온도

  • 정격 최고온도보다 여유를 두세요(예: 1200℃ 정격 → 상시 1050℃ 이하 권장). 발열체·석영튜브 수명 관리를 위해서입니다.

사용 요령

  • 헤드 장착·튜브 교체 — 튜브를 롤러에 균일하게 장착. 눌림이 과하면 튜브 수명·유량 정확도가 떨어집니다.
  • PC 제어 — RS485(Modbus RTU)로 유량·Start/Stop·시퀀스·다펌프 동기. 지원 모델은 위 표의 RS485 ○.
  • 정량 분주 — 점도·튜브에 따라 실제 토출량이 달라집니다. 정밀 분주는 실제 액체로 캘리브레이션하세요.
MFCMFCALICAT · 질량유량계+
Alicat MFC는 SCCM 등 표준 단위로 setpoint를 설정하고, Gas Select™로 98종 이상 가스를 재교정 없이 바꿉니다. (MC 시리즈 전면 버튼 기준)

1) SCCM 유량 설정

  • 단위 확인 — Mass Flow 단위가 SCCM인지 확인. (변경: MENU → Basic Config → DEVICE UNITS → Mass Flow → SCCM → SET)
  • 설정값 입력 — SETPT 소프트키 → 값 입력(예: 100 SCCM) → SET. 실측(Mass Flow)과 설정값이 함께 표시됩니다.
  • 정지 — 설정값을 0으로 하면 밸브를 닫아 정지. 풀스케일 초과값은 입력되지 않습니다.
  • 단위 변환 — 1 SLPM = 1000 SCCM (예: 15.44 SLPM = 15,440 SCCM). 저유량은 SCCM, 대유량은 SLPM이 읽기 편합니다.

2) 가스 변경 (Gas Select™)

  • 메뉴 진입 — MENU → Basic Configuration → GAS.
  • 카테고리 선택 — Standard·Bioreactor·Breathing·Chromatography·Laser·COMPOSER 등 → SELECT.
  • 가스 선택 — Air·N₂·Ar·H₂·He·CO₂·CH₄·CO … 이동 후 SET. 재시작 없이 즉시 반영됩니다.
  • 혼합가스 — 2종 이상은 COMPOSER™ User Mixes로 조성 정의. 부식성·독성 가스는 내식 시리즈(MCS·MCSS) 사양 확인.

⚠ 주의

  • 실제 흐르는 가스와 Gas Select 설정을 반드시 일치시키세요(불일치 시 측정·제어 오차).

직접 해보기 — 가상 시뮬레이터

온도온도컨트롤러SP590 · NOVA500E+
삼흥에너지 전기로에 탑재되는 온도컨트롤러(삼원테크 NOVA500E 시리즈, SP590 등)의 기본 조작·문제해결입니다.

기본 흐름

  • 온도 스케줄 — 세그먼트별 목표온도·시간(램프 상승 / 유지 HOLD / 하강)을 설정.
  • 운전 시작·정지 — RUN / STOP. 시작 조건(STC) 기본은 PV(현재온도), 지정 시작점부터면 STC=SSP + SSP 값 설정.
  • 구간 반복(사이클) — RPT(횟수)·RST(시작)·REN(종료)을 설정, RST ≤ REN. 패턴 전체 반복은 종료동작(LC)을 자기 패턴으로 지정.
  • RS485 통신 — COM.P·BAUD·PRTY·S.BIT·D.LEN·ADDR을 상위 프로그램과 일치, ADDR 중복 금지.

자주 막히는 것 (문제해결)

  • 버튼 무반응 — Key 잠금(LOCK). 제어그룹(G.CTL)의 LOCK 해제.
  • 오토튜닝(AT) 안 됨 — RUN 상태에서만 실행. 운전 시작·센서(PV) 정상 확인 후 G.AT에서 AT=ON.
  • 반복 안 됨 — RPT·RST·REN 설정 및 RST ≤ REN 확인.
  • 세그먼트 멈춤 — 대기동작(Wait). PV가 대기범위(W.ZON)에 들 때까지 대기 → 원치 않으면 W.ZON=OFF.
  • RS485 불통 — 통신옵션 장착·A/B 배선·파라미터 일치·ADDR 중복 확인.
※ 삼원테크 NOVA500E(SP590 등) 사용설명서를 참고한 학습 자료이며, 화면·동작은 실제 제품과 다를 수 있습니다.
