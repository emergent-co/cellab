시린지 펌프 SY-06B

Runze Fluid Syringe Pump SY-06B
60 mm 스트로크 · M01~M12 분배 밸브 선택 · 밸브 전환 ≤280 ms · RS232 / RS485 / CAN

시린지 펌프 SY-06B는 정격 스트로크 60 mm에 분배 밸브를 얹은 밸브 일체형 시린지 펌프 모듈로, 마이크로리터에서 밀리리터까지 자동 피펫팅·희석·분주를 상위 컴퓨터 제어로 수행합니다.

특징

  • 정격 스트로크 60 mm · 6000 스텝(표준 모드) — 스텝당 분해능 0.01 mm입니다
  • 선속도 0.005 ~ 30 mm/s, 정격 스트로크 주행 시간 2 s ~ 12000 s(매질 물)로 극저맥동 정량이 가능합니다
  • 분배 밸브를 M01 · M02 · M03 · M04 · M05 · M06 · M10 · M12 중에서 골라 조합합니다 — 인접 포트 간 전환 시간 ≤280 ms
  • 습부는 붕규산 유리 · PCTFE · 사파이어 · PTFE 로 금속이 없습니다 — 최대 압력 0.7 MPa
  • 구동부는 사다리꼴 나사(리드 2 mm) 이며 TTL 3채널 입력을 받습니다
  • RS232 / RS485 / CAN 제어 — 주소와 파라미터를 통신으로 설정하고 여러 대를 직렬로 연결해 쓸 수 있습니다
  • 제조사는 SY-06B를 60 mm 스트로크 · 마이크로 스테핑 구동 사양의 CX 계열 대체 모델로 안내합니다 (최대 25 mL 정량)

모델 번호 체계 (Model number)

주문 코드는 ZSB-SY06B-60-M□□ 형태로, 60 은 정격 스트로크 60 mm, M□□ 는 조합할 분배 밸브 모델(M01~M12)을 뜻합니다.

분배 밸브 유로 구성 (Valve options)

C 포트가 시린지에 연결되는 공통 포트입니다. 밸브 모델에 따라 유로 논리가 달라집니다.

  • M01 — Y 유로 (C-1 / 1-2 / C-2 연동)
  • M02 — T 유로 (C-1-2 / C-1 / 1-2 / C-2 연동)
  • M03 — 분배 유로 (C-1 / C-2 / C-3 연동)
  • M04 — 라디오 유로 (C-1 / 1-2 / 2-3 / C-3 연동)
  • M05 — 바이패스 유로 (C-1 / 2-3 연동, C-3 / 1-2 연동)
  • M06 · M10 · M12 — 분배 유로 (C 가 1~6 / 1~9 / 1~12 포트에 선택 연결)

시린지 펌프 SY-06B FAQ

사양SY-06B의 정격 스트로크와 분해능은 어떻게 되나요?

정격 스트로크 60 mm에 표준 모드 6000 스텝이며, 스텝당 분해능은 0.01 mm입니다.

속도주입 속도는 어디까지 조절되나요?

선속도 0.005~30 mm/s이고, 정격 스트로크를 주행하는 데 2초에서 12000초까지 걸리도록 설정할 수 있습니다(매질 물 기준).

밸브밸브 모델 M01~M12는 무엇이 다른가요?

유로 논리가 다릅니다. M01은 Y 유로, M02는 T 유로, M03·M04·M05는 3포트 분배·라디오·바이패스 유로이고, M06·M10·M12는 공통 포트가 각각 6·9·12 포트에 선택 연결되는 분배 유로입니다.

재질습부 재질은 무엇인가요?

붕규산 유리, PCTFE, 사파이어, PTFE입니다. 최대 압력 정격은 0.7 MPa입니다.

제어어떤 통신으로 제어하나요?

RS232 · RS485 · CAN을 지원합니다. RS232/RS485는 9600~115200 bps, CAN은 100 Kbps~1 Mbps이며 TTL 3채널 입력도 받습니다.

확장여러 대를 같이 쓸 수 있나요?

직렬로 연결해 여러 대를 함께 제어할 수 있습니다. 주소와 파라미터는 통신으로 설정합니다.

소모품시린지는 어떤 규격을 쓰나요?

정격 스트로크 60 mm 규격의 기밀 시린지를 씁니다. 25 µL부터 250 µL 이상까지 용량별로 선택합니다.
