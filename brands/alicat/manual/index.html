Alicat 질량유량계(MFC) 메뉴얼

전면 버튼으로 SCCM 유량 설정과 Gas Select™ 가스 변경을 단계별로 안내합니다.

Alicat 질량유량계(MFC)는 SCCM 등 표준 유량 단위로 setpoint를 설정하고, Gas Select™로 98종 이상 가스를 재교정 없이 즉시 바꿀 수 있습니다. 아래는 표준 전면 버튼(MC 시리즈) 기준 절차입니다.

직접 해보기 — 가상 시뮬레이터

아래 가상 Alicat MFC를 실제처럼 눌러보세요. SETPT로 유량을 설정하고, MENU → GAS로 가스를 바꿉니다. (전체화면은 시뮬레이터 페이지)

자세한 단계별 설명 (SCCM 유량 설정 · 가스 변경 · 주의)

1. SCCM 단위로 유량 설정하기

SCCM은 표준상태(STP) 기준 cc/min이며 1 SLPM = 1000 SCCM입니다. 단위를 SCCM으로 맞춘 뒤 설정값(SETPT)을 입력합니다.

단위 확인 — 메인 디스플레이의 질량유량(Mass Flow) 단위가 SCCM인지 확인합니다. 맞으면 3단계로.
단위 변경 — MENU → Basic Configuration → DEVICE UNITS → Mass Flow에서 SCCM을 선택하고 확인 화면에서 SET. (STP 기준은 Basic Config → STP/NTP에서 변경)
설정값 진입 — 메인 디스플레이에서 SETPT(setpoint) 소프트키를 누릅니다.
값 입력 — 버튼(UP/DOWN·자리 이동)으로 원하는 유량을 입력합니다. 예: 100 SCCM.
확정 — SET을 누르면 컨트롤러가 밸브를 조절해 설정 유량으로 제어합니다. 실측(Mass Flow)과 설정(SETPT)이 함께 표시됩니다.
정지 — 설정값을 0으로 하면 밸브를 닫아 흐름을 멈춥니다. 풀스케일(full scale)을 넘는 값은 입력되지 않습니다.

SLPM ↔ SCCM 변환

1 SLPM = 1000 SCCM (둘 다 표준상태(STP) 기준 부피유량, cc/min). 단위 전환은 MENU → BASIC CONFIG → DEVICE UNITS → Mass Flow에서 SLPM 또는 SCCM을 고르고 SET. 예: 15.44 SLPM = 15,440 SCCM. 저유량(수십~수백 cc/min)은 SCCM이, 대유량(L 단위)은 SLPM이 읽기 편합니다.

2. 가스 변경하기 (Gas Select™)

공장 교정은 보통 공기(Air) 기준입니다. 다른 가스를 흘릴 때는 Gas Select™로 가스를 바꾸면 물리적 재교정 없이 정확히 측정·제어됩니다.

메뉴 진입 — MENU → Basic Configuration → GAS (Gas Select™·COMPOSER™).
카테고리 선택 — 가스 카테고리(Standard · Bioreactor · Breathing · Chromatography · Laser · COMPOSER User Mixes 등)에서 UP/DOWN 이동 후 SELECT.
가스 선택 — 가스 목록(Air · N₂ · Ar · H₂ · He · CO₂ · CH₄ · CO …)에서 원하는 가스로 이동합니다.
로드 — SET을 누르면 해당 가스 물성이 로드되고 메인 디스플레이로 복귀합니다. 재시작 불필요, 즉시 반영됩니다.
확인 — 현재 선택된 가스는 메인 디스플레이 우측 단위 아래에 표시됩니다(예: N2).

혼합가스·특수가스

2종 이상 혼합은 COMPOSER™ User Mixes에서 조성을 직접 정의합니다. 부식성·독성 가스는 내식 시리즈(MCS·MCSS) 사양을 확인하세요.

⚠ 주의

  • 가스 일치 — 실제 흐르는 가스와 Gas Select 설정을 반드시 일치시키세요(불일치 시 유량 오차).
  • 단위 혼동 — SCCM과 SLPM 혼동 주의 (1 SLPM = 1000 SCCM).
  • Tare(영점) — MCS·MCRS(내식) 계열은 설치 방향 변경 후 영점을 잡으세요.
  • 가연성·독성 가스(H₂ 등) — 누설·환기·점화원·인터록 관리 필수.
