Alicat MCD 시리즈 양방향 질량유량계 Bidirectional MFC

Alicat MCD 시리즈는 밸브 2개로 양방향 유량을 제어하는 질량유량계(MFC)입니다. 0.5 SCCM~3,000 SLPM, 밀폐 용기 주입·배기에 씁니다.

Alicat MCD 시리즈는 표준 MC에 하류 비례 밸브를 하나 더 얹은 구성입니다. 밸브가 상류·하류 두 개라 밀폐된 용기에 가스를 주입하면서 동시에 반대 방향으로 배기할 수 있습니다. 챔버 압력을 유지하며 가스를 교체하거나, 진공 퍼지를 반복하거나, 유로가 복잡한 시스템에서 한 지점의 유량을 양방향으로 잡아야 할 때 사용합니다. 전용 데이터시트는 없고 베이스 시리즈(MC·MCS·MCW·MCQ)의 사양을 그대로 따릅니다. 성능은 동일하고 밸브가 추가된 만큼 치수만 커집니다.

기본 구성 (Standard)

  1. MCD 본체 — 유량 레인지 지정 (0.5 SCCM ~ 3,000 SLPM)
  2. 비례 밸브 2개 — 상류(주입) + 하류(배기)
  3. Gas Select™ 98종(MCDS는 최대 130종) + COMPOSER™ 혼합가스 20종
  4. 디스플레이 — 흑백 LCD(기본) 또는 컬러 TFT
  5. 통신 — RS-232 Serial + Modbus RTU 기본 / RS-485·Modbus TCP/IP·DeviceNet·EtherCAT·EtherNet/IP·PROFIBUS·PROFINET·IO-Link 선택
  6. 베이스 사양 선택 — MCD(표준) / MCDS(부식성) / MCDW(저압) / MCDQ(고압)

MCD의 성능 사양은 베이스 시리즈 데이터시트를 그대로 적용합니다. 밸브가 하나 더 붙는 만큼 외형 치수와 무게가 베이스보다 커지므로, 랙 설치 시 실제 도면을 요청해 주세요.

사양 (베이스 시리즈 기준)

Alicat은 MCD 전용 데이터시트를 별도로 내지 않고, 베이스 시리즈(MC·MCS·MCW·MCQ)의 사양을 그대로 적용한다고 안내합니다. 성능은 동일하고 밸브 추가로 치수만 달라집니다.

이 제품 FAQ

용도양방향 제어가 왜 필요한가요?

밀폐된 용기나 챔버는 가스를 넣으면 압력이 올라가고 빼면 내려갑니다. 단방향 MFC 한 대로는 넣는 쪽만 제어되므로 배기용 밸브를 따로 달고 별도로 제어해야 합니다. MCD는 상류·하류 밸브를 하나의 제어 루프에서 다루므로, 챔버 압력을 유지한 채 가스를 교체하거나 정해진 유량으로 배기하는 동작을 한 대로 구성할 수 있습니다.

적용어떤 실험에 쓰나요?

대표적으로 진공 퍼지 반복(챔버를 비우고 불활성 가스로 채우는 사이클), 밀폐 챔버 압력 유지형 가스 교체, 리크 테스트 유로, 양방향 유로가 있는 복합 배관에서의 유량 계측·제어가 있습니다. 배터리·소재 분야에서는 글로브박스나 밀폐 반응기의 분위기 치환에 사용합니다.

사양전용 데이터시트가 없다는 게 무슨 뜻인가요?

Alicat은 MCD를 독립 시리즈가 아니라 밸브 구성 옵션으로 취급합니다. 따라서 정확도·응답·압력강하·턴다운 같은 성능 값은 베이스 시리즈(MC·MCS·MCW·MCQ) 데이터시트를 그대로 보시면 됩니다. 달라지는 것은 외형 치수와 무게뿐이며, 이 값은 주문 사양에 따라 도면으로 제공됩니다.

선정베이스는 어떻게 고르나요?

사용 조건으로 정합니다. 비부식성 가스에 일반 압력이면 MCD, 부식성 가스면 MCDS(접액부 316L·FFKM, 최대 130종 가스), 공급압이 거의 없는 저압 라인이면 MCDW(Whisper 기반, 11.5~60 PSIA), 160 PSIA를 넘는 고압이면 MCDQ(11.5~320 PSIA)입니다. 유량 범위 상한은 어느 베이스든 3,000 SLPM입니다.

구매·A/S국내에서 구매·A/S는 어떻게 되나요?

실험셋업연구소가 Alicat 질량유량계를 정품으로 안내하고, 다중 MFC 동기 제어 시스템 연동까지 지원합니다. A/S는 Alicat 국내 총판을 통해 진행되며, 접수·진행 상황은 실험셋업연구소가 함께 챙깁니다. 유량 범위·가스 종류·공급압·통신 방식만 알려주시면 모델을 좁혀 견적을 드립니다.
