모델 · 용량 · 소비자가 (2종)

101018 — 다기능 가스확산 전해셀 (4모드 샌드위치)High-End Multifunctional Gas Diffusion Electrolytic Cell

101018로 구매하는 것 = 고순도 티타늄 + PEEK 샌드위치 판 세트(A·B·C·D) + 체결부 + 피팅 (7,612,500원)판 조합만 바꾸면 네 가지 셀이 됩니다 — 셀을 네 대 사는 대신 하나로 해결하는 구조입니다.
① CO₂ 환원 가스확산 전해셀 · ② 고체전해질 셀(A·B·C 조립 — 이온교환수지 기반 고체전해질로 액체 전해질을 대체해 추가 이온 없이 고순도 액체 생성물을 직접 제조) · ③ 막전극 반응기(A·C 조립, B·D 제거) · ④ 아연-공기 / 리튬-공기 전지(A·B·C 조립 — A와 B 사이 카본페이퍼, B와 C 사이 아연판 또는 리튬판).
가스확산 전극·이온교환막·이온교환수지·금속판은 미포함입니다.

카탈로그 40~43·46페이지 원문

특징·사용 안내

  • 판 조합으로 4가지 셀 — 연구 초기에 여러 방식을 비교할 때 셀 값을 크게 아낍니다
  • 고체전해질 모드는 액체 전해질을 안 써서 염 이온이 섞이지 않은 고순도 액체 생성물을 얻습니다
  • A·C 판의 사행 유로가 기체 체류시간을 늘려 전환효율을 올립니다
  • 모드마다 필요한 소모품이 다릅니다 — 수지·막·금속판을 미리 확인하십시오
  • 가습한 CO₂를 A판으로 넣는 것이 표준 운전 방식입니다

101019 — MEA형 가스확산 전해셀 (궁극형)Ultimate Version Membrane Electrode Gas Diffusion Electrolytic Cell

101019로 구매하는 것 = MEA 기반 가스확산 전해셀 본체 + 사행 유로 가스실 + 체결부 (6,851,200원)막전극 전해셀을 기반으로 전면 업그레이드한 모델입니다. 가스실에 MEA 셀에서 흔히 쓰는 사행 유로를 적용해 반응 기체와 음극의 접촉 시간을 크게 늘렸습니다.
음극실 유로를 새로 설계해 양·음극 간격이 0.4 mm까지 좁아졌습니다 — 이 계열에서 가장 좁습니다. 간격이 좁으면 용액 저항이 줄어 같은 전류에서 셀 전압이 낮아집니다.
가스확산 전극·이온교환막·촉매는 미포함입니다.

다기능 · MEA형 가스확산 전해셀 FAQ

구성가스확산 전극(GDE)도 같이 오나요?

아니요. 셀 본체만 판매합니다. 가스확산 전극(카본페이퍼·카본천), 이온교환막, 촉매는 사용자가 준비하시거나 소모품 페이지에서 따로 주문하십니다.

4모드101018의 네 가지 모드가 무엇인가요?

판 A·B·C·D의 조합을 바꿔 씁니다. ① CO₂ 환원 가스확산 전해셀, ② 고체전해질 셀(A·B·C 조립), ③ 막전극 반응기(A·C만 조립, B·D 제거), ④ 아연-공기·리튬-공기 전지(A·B·C 조립, A와 B 사이 카본페이퍼, B와 C 사이 금속판)입니다.

고체전해질고체전해질 모드가 왜 유용한가요?

액체 전해질을 이온교환수지 기반 고체전해질로 대체하면 생성물에 염 이온이 섞이지 않습니다. 포름산 같은 액체 생성물을 정제 없이 고순도로 바로 얻을 수 있어 후처리가 크게 줄어듭니다.

간격양·음극 간격이 왜 중요한가요?

간격이 좁을수록 용액 저항이 줄어 같은 전류에서 셀 전압이 낮아집니다. 발열과 부반응이 줄고 에너지 효율이 올라갑니다. 다만 너무 좁으면 기포가 빠져나가지 못해 오히려 저항이 튀므로, 전류밀도와 유량에 맞춰 골라야 합니다.

선택101018과 101019 중 어느 쪽인가요?

여러 방식을 비교해야 하면 4모드 다기능인 101018, 이미 MEA 방식으로 정해졌고 셀 전압을 최대한 낮춰야 하면 간격 0.4 mm인 101019입니다. 101019가 오히려 더 저렴합니다.

조립간격 0.4 mm는 조립이 어렵지 않나요?

까다롭습니다. 판면에 이물이 있거나 막에 주름이 지면 바로 단락되거나 새기 쉽습니다. 조립 전 판면을 닦고 막을 평평하게 펴서 올린 뒤 볼트를 대각선 순으로 균일하게 조이십시오.

소모품모드별로 무엇을 준비해야 하나요?

CO₂ 환원과 막전극 모드는 가스확산 전극(카본페이퍼)과 이온교환막, 고체전해질 모드는 추가로 이온교환수지, 금속공기전지 모드는 아연판 또는 리튬판이 필요합니다. 모두 별도 준비 항목입니다.

가격표기 가격 기준이 어떻게 되나요?

표기 가격은 소비자가이며 부가세 별도입니다. 국제 배송료 145,000원이 별도이며, 해외 직수입 품목으로 상시 할인 대상이 아닙니다.
