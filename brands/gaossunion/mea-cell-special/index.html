모델 · 용량 · 소비자가 (6종)

MEA-가시화형 (Type A · Type B) — 가시화 막전극 전해셀Visualizable Membrane Electrode Electrolysis Cell

MEA-가시화형으로 구매하는 것 = 양·음극 광학 창이 달린 바이폴라 플레이트 + 체결부 + 피팅10×10·20×20 mm·5 cm² 6,597,500원이며 30×30·50×50 mm 는 가격문의입니다.
Type A 는 원형 창, Type B 는 사각 창으로 실험 요구에 따라 고릅니다 — 같은 가격입니다. 음극은 중공 사행 유로, 양극은 중공 다중 평행 유로입니다. 막전극·이온교환막·GDL 은 미포함이며 고속 카메라도 별도입니다.

카탈로그 27·28·35페이지 원문

특징·사용 안내

  • 양·음극 양쪽에 창이 있어 두 반응을 동시에 관찰할 수 있습니다
  • 고속 촬영으로 기포 생성·이탈 거동을 직접 봅니다 — 물질 전달 해석의 근거
  • 창 형상은 Type A 원형 / Type B 사각 두 가지이고 가격은 같습니다
  • 유로가 중공(hollow) 구조라 일반 유로보다 관찰 시야가 넓습니다
  • 30×30 mm 이상은 가격문의입니다

MEA-TI-RM — in-situ 라만 막전극 전해셀In-situ Raman Membrane Electrode Electrolysis Cell

MEA-TI-RM으로 구매하는 것 = 티타늄 플레이트 + 석영/사파이어 창 + 금도금 구리 탭 + PEEK 퀵커넥트 피팅 (14×14 mm, 7,612,500원)막전극 전해 조건 그대로 in-situ 라만을 걸도록 만든 셀입니다. 창~시료 거리 5 mm 미만이라 라만 대물렌즈의 작동거리 안에 들어옵니다.
창은 석영판 또는 사파이어 중에 고르고, 유로 크기 14×14 mm 는 맞춤 가능합니다. 알칼리 내식성이 필요하면 고순도 니켈판으로 맞춤 제작합니다.

카탈로그 30·35페이지 원문

특징·사용 안내

  • 창~시료 5 mm 미만 — 장초점 대물렌즈로 촉매 표면을 직접 봅니다
  • MEA 전해 조건(고전류·유동)에서 촉매가 어떻게 변하는지 실시간으로 추적합니다
  • 탭이 금도금 구리라 대전류에서도 접촉 저항이 안정적입니다
  • 피팅이 PEEK 퀵커넥트라 튜빙 탈착이 빠르고 내식성이 좋습니다
  • 알칼리 조건이면 니켈판 맞춤을 검토하십시오 (별도 견적)

유로 교체형 막전극 전해셀Replaceable Flow Channel Membrane Electrode Electrolysis Cell

유로 교체형으로 구매하는 것 = PTFE 바이폴라 플레이트 + 티타늄 체결 보호판 + PTFE 유로판30×30 mm 6,597,500원이며 50×50·100×100 mm 는 가격문의입니다.
유로가 PTFE 별판이라 두께를 바꿔 끼울 수 있습니다 — 최소 0.1 mm까지. 유로 두께가 물질 전달과 압력 손실을 좌우하므로, 조건을 바꿔가며 최적점을 찾는 실험에 맞습니다.
최소 크기가 30×30 mm라 더 작은 규격은 없습니다.

카탈로그 31·35페이지 원문

특징·사용 안내

  • 유로 두께를 갈아 끼우며 물질 전달 조건을 바꿀 수 있습니다 — 최소 0.1 mm
  • 플레이트가 전체 PTFE라 강산·강알칼리에서도 부식되지 않습니다
  • PTFE 는 무르므로 체결 보호판(티타늄)으로 눌러 형상을 유지합니다
  • 최소 30×30 mm — 더 작은 유로는 제작하지 않습니다
  • 50×50 mm 이상은 가격문의입니다

MEA-TI-X — 막전해 스택 전기화학 셀Membrane Electrolysis Stack Electrochemical Cell

MEA-TI-X로 구매하는 것 = 티타늄 유로판 5장 적층 스택 + 금도금 탭 + 체결부 (10×10·20×20 mm·5 cm², 가격문의)유로판을 적층해 전압과 출력을 키우는 스택 셀입니다. 유로판은 고순도 티타늄이며 고순도 니켈·PEEK 맞춤이 가능합니다.
유로 연결 방식이 두 가지입니다 — 음·양극 모두 직렬(수전해 수소 생산용), 음극 직렬 + 양극 병렬 독립 유로(양극 발생 기체를 빠르게 배출, CO₂ 환원용).
카탈로그에 “Inquiry”로만 적혀 있어 가격문의로 안내합니다.

카탈로그 32·33·35페이지 원문

특징·사용 안내

  • 단셀보다 전압과 출력이 커져 실제 전해조 거동에 가까워집니다
  • 전직렬은 수전해 수소 생산에, 음극직렬+양극병렬은 CO₂ 환원에 씁니다
  • 양극 병렬 독립 유로는 발생 기체를 빠르게 빼내 전극이 덮이는 것을 막습니다
  • 유로판 장수와 연결 방식에 따라 견적이 달라져 가격문의입니다

특수 막전극 전해셀 FAQ

구성막전극(MEA)도 같이 오나요?

아니요. 전해셀 본체(바이폴라 플레이트·체결부·피팅)가 구매 구성입니다. 촉매를 담지한 막전극 어셈블리, 이온교환막, 가스확산층(GDL)은 사용자가 준비하시거나 소모품 페이지에서 따로 주문하십니다.

가시화Type A와 Type B 중 무엇을 고르나요?

창 형상 차이입니다. Type A는 원형, Type B는 사각 창이며 가격은 같습니다. 고속 카메라의 촬영 영역과 유로 형상에 맞춰 고르시면 됩니다. 사각 창이 유로 전체를 한 번에 담기에 유리한 경우가 많습니다.

라만MEA-TI-RM은 일반 in-situ 라만 셀과 무엇이 다른가요?

C031 계열 in-situ 라만 셀은 전해액에 잠긴 전극을 봅니다. MEA-TI-RM은 막전극 전해 조건, 즉 고전류·유동·가스 공급이 걸린 상태에서 촉매 표면을 봅니다. 실제 전해조에 가까운 조건에서의 촉매 변화를 보려면 이쪽입니다.

유로 두께유로 두께가 왜 중요한가요?

얇으면 유속이 빨라져 물질 전달은 좋아지지만 압력 손실이 커지고 막힘 위험이 늘어납니다. 두꺼우면 반대입니다. 최적점은 촉매와 전류밀도에 따라 달라지므로 두께를 갈아 끼우며 찾는 것이 유로 교체형의 목적입니다.

유로 크기유로 교체형을 20×20 mm로 만들 수 있나요?

아니요. 카탈로그에 최소 30×30 mm이며 더 작은 규격은 제공하지 않는다고 명시돼 있습니다. 작은 유로가 필요하면 MEA-TI-TI 계열을 보십시오.

스택스택의 유로 연결 방식은 어떻게 고르나요?

음·양극 모두 직렬로 잇는 방식은 수전해 수소 생산에 씁니다. 음극은 직렬, 양극은 병렬 독립 유로로 두는 방식은 양극에서 나오는 기체를 빠르게 빼낼 수 있어 CO₂ 환원에 적합합니다.

가격왜 문의가 많나요?

카탈로그 35페이지 종합표에 대면적 규격과 스택이 "Inquiry"로만 적혀 있습니다. 유로판 장수, 연결 방식, 재질 변경에 따라 견적이 달라지는 항목이라 그렇습니다.

가격표기 가격 기준이 어떻게 되나요?

표기 가격은 소비자가이며 부가세 별도입니다. 국제 배송료 145,000원이 별도이며, 해외 직수입 품목으로 상시 할인 대상이 아닙니다.
